Why nothing is uploaded

Traditional online converters send your document to a server, process it there, and ask you to trust a privacy policy about what happens next. {{ site.name }} does the work in the same tab you are reading this in, using the browser's own PDF, ZIP, image and crypto engines.

That means contracts, payslips and client spreadsheets are never sent anywhere — and it is why the tools keep working when your connection drops.

Read the privacy model
  • No file ever leaves the device There is no upload endpoint to send it to; the tools run in your browser.
  • Heavy work runs off the main thread Hashing, parsing and rendering happen in Web Workers, so the UI stays smooth.
  • Installable and offline-capable Add it to your desktop and the whole toolkit keeps working on a plane.
  • No analytics on your documents We cannot see what you convert, because it never reaches us.
